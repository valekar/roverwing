# Rover Wing

Portfolio site for Rover Wing, animated research-based educational explainer Shorts for companies.

Static HTML, no build step. Served by GitHub Pages from the `gh-pages` branch (root). Push changes to `gh-pages` to update the live site (or switch Settings → Pages → Source to `main`).
Live: https://valekar.github.io/roverwing/
